Conceptos de Progra. Orientada a Objetos

Juan Sebastian Olivera, Nadia malaver

La Programación Orientada a Objetos (POO) es un paradigma de programación que organiza el código en base a "objetos", los cuales representan elementos del mundo real dentro de un programa.

Objeto

Un objeto es una representación de una entidad del mundo real dentro de un programa.

Alumno → nombre, edad, notas

Acciones → estudiar(), rendirExamen()

Clase

// 1. Clase

constructor(nombre, edad) {
this.nombre = nombre;
this.edad = edad;
}

saludar() {
console.log("Hola, mi nombre es " + this.nombre);
}

}

// 5. Encapsulamiento

class CuentaBancaria {

constructor(titular) {
this.titular = titular;
this._saldo = 0;
}

depositar(monto) {
this._saldo += monto;
}

verSaldo() {
return this._saldo;
}

}
