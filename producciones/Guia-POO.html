Programación Orientada a Objetos

Juan Sebastian Olivera

Imaginen que tienen que explicarle a alguien cómo funciona el celular que usan todos los días.

Si el teléfono estuviera hecho con programación tradicional, sería como una receta gigante donde todo está mezclado. Para mandar un mensaje, el sistema tendría que ocuparse manualmente de cada detalle: escribir el texto, prender la pantalla, conectarse a Internet, buscar el contacto y enviar el mensaje. Todo dependería de una enorme lista de instrucciones paso a paso. El problema es que, si una parte cambia o falla, muchas otras también dejan de funcionar. Sería como intentar arreglar una bicicleta donde todas las piezas están pegadas entre sí.

La Programación Orientada a Objetos propone una idea diferente. En vez de tener una sola receta gigante, el celular está dividido en pequeñas partes inteligentes que trabajan juntas.

Por ejemplo, existe un Contacto. Ese contacto sabe guardar un nombre, un número y una foto. También sabe hacer ciertas tareas, como mostrar su información o cambiar el número. Lo mismo pasa con un Mensaje: sabe cuál es su texto, a qué hora fue enviado y si ya fue leído.

Cuando usás el celular, el sistema crea ejemplos reales de esas cosas. Por eso aparece el contacto "Mamá" o el mensaje "Ya llegué". Cada uno funciona como un objeto independiente dentro del sistema.

Lo importante es que cada objeto se encarga de su propio trabajo. Cuando tocás el botón de enviar, el botón simplemente le pide al mensaje que se envíe. No necesita saber cómo funciona Internet ni cómo llega el mensaje al otro teléfono. Cada parte cumple su función sin meterse en la de las demás.

Además, los objetos protegen su información. Si querés cambiar el número de un contacto, no entrás a modificar datos internos del celular directamente; usás las opciones que el propio contacto permite.

De esta forma, el software deja de ser una lista rígida de instrucciones y pasa a funcionar como un equipo de pequeñas partes organizadas que cooperan entre sí.

Objeto

Un objeto es una representación de una entidad del mundo real dentro de un programa. Cada objeto tiene:

  • Atributos: sus características
  • Métodos: las acciones que puede realizar
Ejemplo:

Un alumno puede tener: nombre, edad, notas.

Y puede realizar acciones como: estudiar(), rendirExamen().

Clase

Una clase es un molde o plantilla que se utiliza para crear objetos. Define qué atributos tendrán y qué métodos podrán ejecutar.

Ejemplo:

La clase Alumno define cómo serán todos los alumnos del sistema.

// CLASE: es el molde para crear objetos
class Persona {
constructor(nombre, edad) {
this.nombre = nombre; // atributo
this.edad = edad; // atributo
}

// método (acción)
saludar() {
console.log("Hola, mi nombre es " + this.nombre);
}
}

// OBJETO: instancia de la clase
// const persona1 = new Persona("Juan", 16);

// uso del método
// persona1.saludar();

Atributo

Un atributo es una propiedad o característica de un objeto. Puede ser de distintos tipos: número, texto, booleano.

Ejemplo:

nombre = "Juan"
edad = 16
aprobado = true

Método

Un método es una función que pertenece a un objeto y define su comportamiento.

Ejemplo:

calcular Promedio(), aprobarMateria()

Abstracción

La abstracción consiste en simplificar la realidad, representando solo los aspectos importantes de un objeto y dejando de lado los detalles innecesarios.

Ejemplo:

En un sistema de gestión de alumnos, lo que nos interesa de un objeto Alumno es su nombre y sus notas, pero no nos interesa el color de su pelo o su comida favorita.

Encapsulamiento

Consiste en proteger los datos de un objeto, evitando que se pueda acceder a ellos directamente desde fuera de la clase.

class CuentaBancaria {

constructor(titular) {
this.titular = titular;
this._saldo = 0; // "privado" (convención con_)
}

// método para depositar dinero
depositar(monto) {
this._saldo += monto;
}

// método para ver el saldo
verSaldo() {
return this._saldo;
}

}

// const cuenta = new CuentaBancaria("Carlos");
// cuenta.depositar(1000);
// console.log(cuenta.verSaldo()); // 1000

Herencia

Mecanismo que permite crear una clase nueva a partir de una clase existente. La clase nueva (clase hija) hereda los atributos y métodos de la clase original (clase padre), y puede agregar los suyos propios.

// Clase base
class Animal {
hacerSonido() {
console.log("El animal hace un sonido");
}
}

// Clase hija
class Perro extends Animal {
hacerSonido() {
console.log("El perro ladra");
}
}

// const perro = new Perro();
// perro.hacerSonido();

Polimorfismo

El polimorfismo es la capacidad de que distintos objetos respondan de manera diferente ante un mismo método.

Ejemplo del taller:

En un sistema educativo, tanto un AlumnoRegular como un AlumnoLibre tienen un método calcularNotaFinal(), pero cada uno lo hace de manera distinta (el regular promedia parciales y el libre rinde un examen final).

class Animal {
hacerSonido() {
console.log("Sonido genérico");
}
}

class Gato extends Animal {
hacerSonido() {
console.log("Miau");
}
}

class Vaca extends Animal {
hacerSonido() {
console.log("Muuu");
}
}

// const animales = [new Gato(), new Vaca()];
// mismo método, distinto comportamiento
// animales.forEach(animal => {animal.hacerSonido();});

Delegación

Ocurre cuando un objeto le pide a otro objeto que realice una tarea por él.

Ejemplo:

Un objeto Alumno no calcula su nota final él mismo, sino que le pide a un objeto Profesor que lo haga.

class Impresora {
imprimir(texto) {
console.log("Imprimiendo: " + texto);
}
}

class Documento {
constructor(contenido, impresora) {
this.contenido = contenido;
this.impresora = impresora;
}

imprimirDocumento() {
// delega la tarea a la impresora
this.impresora.imprimir(this.contenido);
}
}

// const impresora = new Impresora();
// const doc = new Documento("Hola mundo", impresora);
// doc.imprimirDocumento();

Colecciones (Listas)

Las colecciones permiten almacenar y manipular grupos de objetos.

class Jugador {
constructor(nombre) {
this.nombre = nombre;
}
}

class Equipo {
constructor(nombre) {
this.nombre = nombre;
this.jugadores = []; // colección (array)
}

agregarJugador(jugador) {
this.jugadores.push(jugador);
}

listarJugadores() {
console.log("Lista de jugadores de " + this.nombre);
// recorrer la lista
this.jugadores.forEach(jugador => {
console.log(jugador.nombre);
});
}
}
